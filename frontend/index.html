02 - METHOD

Four signals, read together

No single signal proves anything alone. Veritas is built to weigh them against each other before it commits to a read.

SRC

Source pattern

Who's publishing, how long they've existed, and whether their past claims held up.

LNG

Language pressure

Flags urgency, outrage bait, and absolutist wording that's built to bypass scrutiny.

CLM

Claim consistency

Checks the core claim against independent, already-verified reporting.

MED

Media forensics

Screens attached images for manipulation, mismatched context, or reuse.
