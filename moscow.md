# MoSCoW Prioritization

## Must Have (Essential Features)

- User registration
- User login
- News URL input
- News paragraph input
- AI fake news detection
- Search trusted news websites
- Display Real/Fake result
- Show confidence score
- Display verification sources

---

## Should Have (Important Features)

- Search history
- User dashboard
- Password reset
- Mobile responsive design
- Explain why news is fake or real

---

## Could Have (Nice to Have)

- Dark mode
- Multi-language support
- Voice input
- Download verification report
- Email verification

---

## Won't Have (Not in this Version)

- Mobile application
- Browser extension
- Social media integration
- Live TV news monitoring
- Premium subscription
